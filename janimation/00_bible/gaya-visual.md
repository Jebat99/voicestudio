# Panduan Gaya Visual

## Identiti gaya

**Kartun 2D gaya anime moden**: garisan luar bersih dan tegas, *cel shading* dua tona
(satu tona bayang sahaja), mata besar ekspresif dengan kilauan putih, warna cerah dan
tepu sederhana, latar belakang lukisan lembut yang sedikit kabur supaya watak menonjol.

Rasa keseluruhan: komedi sekolah anime yang ceria, bertukar ke suasana misteri
(warna sejuk, bayang panjang) apabila cerita menjadi tegang.

## Palet warna

| Kegunaan | Warna | Hex |
|---|---|---|
| Langit / siang | Biru langit cerah | `#7EC8F2` |
| Dinding sekolah | Krim pucat | `#F3E9D2` |
| Aksen sekolah (bumbung, pintu) | Hijau tua | `#2F6B4F` |
| Uniform kemeja | Putih bersih | `#FAFAFA` |
| Seluar murid lelaki | Hijau gelap | `#24452F` |
| Kain murid perempuan | Biru tua | `#1F3A6B` |
| Suasana misteri | Ungu kebiruan | `#3B3A6E` |
| Aksen kejutan / komedi | Kuning terang | `#FFD23F` |
| Garisan luar | Coklat kehitaman (bukan hitam pekat) | `#2B1E1A` |

## Dua mod suasana

| Mod | Bila | Pencahayaan | Warna |
|---|---|---|---|
| **Komedi** | Lawak, siang, kantin | Cahaya matahari terang, bayang lembut | Hangat, tepu, kuning dan biru |
| **Misteri** | Petunjuk, blok lama, petang | Cahaya sisi, bayang panjang, vignet | Sejuk, ungu kebiruan, kontras tinggi |

Peralihan mod mesti jelas: perubahan warna mendadak membantu penonton rasa "ada sesuatu".

## Reka bentuk watak (am)

- Kepala sedikit besar (nisbah badan ±1:6), mata besar, hidung kecil satu garisan.
- Setiap watak mesti ada **siluet unik** (bentuk rambut, aksesori) supaya mudah dikenali
  walaupun kecil di skrin telefon.
- Setiap watak mesti ada **satu warna tanda** pada aksesori.
- Uniform sekolah menengah Malaysia (rekaan): kemeja putih; lelaki seluar panjang hijau
  gelap; perempuan baju kurung putih, kain biru tua, tudung putih.

## Bahasa ekspresi anime (gunakan dengan bebas untuk komedi)

| Ekspresi | Teknik visual |
|---|---|
| Terkejut | Mata putih bulat tanpa anak mata, rambut tegak, latar kilat kuning |
| Malu | Pipi merah berjalur, wap keluar dari kepala |
| Marah | Urat silang di dahi, api di latar, gigi taring kecil |
| Takut | Muka pucat kebiruan, garisan menegak di dahi, badan menggigil |
| Gelabah | Peluh besar menitis, mata berpusing |
| Bangga | Mata tertutup, hidung ke atas, kilauan di latar |
| Mengalah | Badan jadi putih/kelabu, roh keluar dari mulut |
| Curiga | Mata separuh tertutup, kamera dekat, latar gelap |
| Chibi | Badan mengecil (gaya chibi) untuk reaksi lawak sekejap, 1–2 s |

## Larangan visual

- Tiada teks, logo atau huruf dalam visual janaan AI (sari kata ditambah kemudian).
- Tiada gaya 3D, realistik, fotografi atau tanah liat (*claymation*).
- Tiada tiruan watak atau reka bentuk anime sedia ada.
- Jangan ubah warna uniform atau aksesori tanda watak.
