# FIGURAN — Watak Sampingan Berulang dan Orang Ramai

> Status: **DRAF**. Blok di sini disalin tepat seperti Blok Kunci Rupa.
> Figuran ringkas supaya tidak mencuri perhatian daripada watak utama.

### Blok Varian PAKCIK-GYM

```
PAKCIK-GYM: lelaki Melayu tua 65 tahun, badan kurus tetapi berurat, kepala botak berkilat
dengan rambut putih nipis di sisi, misai putih tebal melengkung, mata kecil bersemangat,
singlet putih, seluar trek merah, ikat kepala merah, kasut sukan putih, warna tanda merah.
```

### Blok Varian JURUNIKAH

```
JURUNIKAH: lelaki Melayu 50-an, badan sederhana berisi, janggut putih pendek kemas, cermin
mata segi empat bingkai hitam tebal, muka ramah tetapi letih, baju Melayu putih kemas,
songkok hitam, sapu tangan putih di tangan, pen di poket dada, warna tanda hijau.
```

### Blok Varian LELAKI-FIGURAN

```
LELAKI-FIGURAN: sekumpulan lelaki dewasa Malaysia pelbagai bangsa dan bentuk badan, pakaian
kasual harian (baju-T, kemeja, seluar jeans), muka ringkas tanpa ciri menonjol, ekspresi
kartun yang dilebih-lebihkan.
```

### Blok Varian WANITA-FIGURAN

```
WANITA-FIGURAN: ramai wanita dewasa Malaysia pelbagai bangsa, kebanyakan bertudung, berpakaian
sopan dan kemas (baju kurung, blaus, seluar panjang), berjalan dengan yakin dan ceria, muka
ringkas tanpa ciri menonjol.
```

### Blok Varian PEKERJA-FIGURAN

```
PEKERJA-FIGURAN: pekerja kedai dan katering Malaysia berpakaian apron dan uniform kerja kemas,
muka ringkas tanpa ciri menonjol, bergerak sangat sibuk.
```

### Blok Varian MURID-FIGURAN

```
MURID-FIGURAN: murid sekolah menengah Malaysia, lelaki berkemeja putih bertali leher hijau
dan berseluar hijau gelap, perempuan berbaju kurung putih, kain biru tua dan tudung putih,
muka ringkas tanpa ciri menonjol.
```
