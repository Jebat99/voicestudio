## Blok Kunci Latar

### LOK-KELAS4A
```
LOK-KELAS4A: bilik darjah sekolah menengah Malaysia, papan hitam hijau di depan dengan meja
guru kayu, empat baris meja dan kerusi kayu murid, tingkap nako kaca berbingkai hijau di
sebelah kiri dengan langsir biru pudar, kipas siling berputar perlahan, jam dinding bulat
di atas papan hitam, dinding krim pucat dengan papan kenyataan berwarna-warni di belakang.
```

### LOK-KORIDOR
```
LOK-KORIDOR: koridor terbuka tingkat dua sekolah, lantai jubin merah bata, tembok separas
pinggang berwarna krim dengan jeriji hijau tua, pintu kelas kayu hijau di sebelah kanan
berderet, rak kasut kecil di tepi setiap pintu, pemandangan padang sekolah hijau dan
pokok angsana di sebelah kiri.
```

### LOK-KANTIN
```
LOK-KANTIN: kantin sekolah separuh terbuka, meja panjang besi dengan bangku biru, kaunter
makanan dengan dulang nasi lemak dan kuih di bawah kanopi hijau, kipas dinding besar,
peti ais minuman di sudut, papan menu kapur di dinding, lantai simen kelabu.
```

### LOK-PERPUS
```
LOK-PERPUS: perpustakaan sekolah yang sunyi, rak buku kayu tinggi berderet membentuk
lorong, meja bacaan panjang dengan lampu meja hijau, kaunter pengawas di pintu masuk,
cahaya matahari masuk serong melalui tingkap tinggi, habuk berkilau di udara.
```

### LOK-BLOKC
```
LOK-BLOKC: blok bangunan sekolah lama dua tingkat yang hampir ditinggalkan, cat krim
mengelupas dengan kesan lumut, tangga simen retak, pintu Bilik Muzik kayu coklat tua
berkunci mangga besar berkarat, tingkap kaca berdebu, daun kering di lantai, pokok besar
menaungi bangunan.
```

### LOK-PONDOK
```
LOK-PONDOK: pondok pengawal kecil di sebelah pagar besi hijau sekolah, meja kecil dengan
buku log dan radio lama, papan kunci di dinding dengan gugusan kunci berlabel, lampu
kalimantang berkelip, kerusi plastik merah, palang pagar kuning-hitam.
```

## Varian suasana

| Lokasi | Komedi (siang) | Misteri |
|---|---|---|
| Semua | Cahaya matahari terang, warna hangat | Petang jingga atau malam biru-ungu, bayang panjang, vignet |
| LOK-BLOKC | Jarang (hanya untuk twist lucu) | Lalai: kabus nipis, cahaya hijau pudar dari tingkap |
