# Kamus Kamera

Istilah dalam storyboard dan prompt. Istilah dalam kurungan digunakan jika alat AI tidak memahami BM.

## Sudut dan saiz syot

| Istilah BM | (Teknikal) | Kegunaan dalam Janimation |
|---|---|---|
| Syot sangat jauh | (extreme wide shot) | Mewujudkan lokasi, Blok C yang menyeramkan |
| Syot jauh | (wide shot) | Seluruh badan watak + latar, lawak fizikal |
| Syot sederhana | (medium shot) | Pinggang ke atas, dialog biasa |
| Syot dekat | (close-up) | Muka, emosi, punchline |
| Syot sangat dekat | (extreme close-up) | Mata, petunjuk kecil, saat twist |
| Dari atas bahu | (over-the-shoulder) | Perbualan dua watak |
| Sudut rendah | (low angle) | Watak nampak hebat atau mengancam (CIKGU-ROS) |
| Sudut tinggi | (high angle) | Watak nampak kecil, takut, kalah |
| Sudut senget | (dutch angle) | Ada yang tak kena, misteri |
| Pandangan watak | (POV shot) | Penonton melihat apa yang watak lihat |
| Dari atas kepala | (top-down shot) | Petunjuk di atas meja, peta |

## Gerakan kamera

| Istilah BM | (Teknikal) | Kegunaan |
|---|---|---|
| Statik | (static) | Lawak reaksi (biar watak bergerak, kamera diam) |
| Zoom masuk pantas | (snap zoom / crash zoom) | Punchline, kejutan, "DUM!" |
| Zoom masuk perlahan | (slow push-in) | Ketegangan meningkat, misteri |
| Zoom keluar | (pull-out / zoom out) | Dedah sesuatu yang lebih besar (twist) |
| Pan kiri / kanan | (pan) | Ikut pandangan, dedah watak tersembunyi |
| Dongak / tunduk | (tilt up / down) | Dedah ketinggian CIKGU-ROS dari kasut ke muka |
| Ikut watak | (tracking shot) | Kejar-mengejar di koridor |
| Goncang | (camera shake) | Hentakan, jeritan, kejutan besar |
| Pusing keliling | (orbit) | Saat dramatik, pendedahan |
