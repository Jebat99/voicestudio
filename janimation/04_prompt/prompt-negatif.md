# Blok Prompt Negatif

> Salin ke `[NEGATIF]` dalam setiap prompt. Jika alat ada medan "negative prompt"
> berasingan, tampal di sana.

```
[NEGATIF] Elakkan: gaya 3D, realistik, fotografi, claymation, gaya Barat atau Disney,
teks, huruf, logo, tera air, sari kata dalam visual, jari berlebihan atau cacat, anggota
badan berganda, muka berubah bentuk, perubahan warna rambut atau pakaian, aksesori hilang,
watak tambahan yang tidak diminta, kabur bergerak berlebihan, bingkai berkelip, latar
belakang berubah di tengah klip, kualiti rendah, pecah piksel.
```

## Tambahan ikut keadaan

| Masalah berulang | Tambah ke negatif |
|---|---|
| Tudung berubah gaya | "tudung bertukar bentuk, rambut kelihatan dari bawah tudung" |
| Cermin mata hilang | "cermin mata hilang atau bertukar bentuk" |
| Jambul AIMAN hilang | "rambut licin tanpa jambul" |
| Kamera bergoyang | "kamera bergegar tanpa sebab" |
| Mulut bergerak bila diam | "mulut bergerak, bercakap" (untuk scene tanpa dialog) |
