# Teknik Animasi 2D yang Menarik

Teknik untuk membuat animasi lebih hidup dan lebih "TikTok-able". Pilih 1–2 setiap scene.
Jangan guna semuanya sekali.

## Teknik gerakan

| Teknik | Keterangan dalam prompt | Bila guna |
|---|---|---|
| Picit dan regang | "badan memampat sebelum melompat, kemudian meregang memanjang" | Lompat, terkejut, jatuh |
| Bingkai calit | "kesan calitan gerakan pantas (smear frame)" | Lari laju, pusing kepala, tampar meja |
| Garis kelajuan | "garis kelajuan di latar belakang" | Kejar-mengejar, berlari |
| Bingkai hentakan | "bingkai hentakan dengan latar bertukar warna terbalik selama sekelip mata (impact frame)" | Klimaks, twist, kejutan besar |
| Bersedia dahulu | "watak menarik badan ke belakang sebelum berlari" | Sebelum aksi besar |
| Ikut lambat | "tudung dan tali leher bergerak sedikit lambat selepas badan berhenti" | Brek mengejut, pusing |
| Pegun sekejap | "watak membeku dalam pose seketika" | Sebelum punchline |

## Teknik komedi visual

| Teknik | Contoh |
|---|---|
| Chibi seketika | AIMAN mengecil jadi chibi bila malu, 1–2 s |
| Latar bertukar | Latar jadi kilat kuning bila terkejut, api bila marah |
| Roh keluar | Roh putih keluar dari mulut APIS bila keropok habis |
| Kelip cermin mata | Kanta QIS berkilat putih sebelum dia menyampaikan teori |
| Muncul dari belakang | CIKGU-ROS muncul dalam bayang tanpa bunyi di belakang watak |
| Potong ke reaksi | Lawak diucapkan → potong terus ke muka datar QIS |

## Teknik misteri

| Teknik | Contoh |
|---|---|
| Petunjuk di latar | Objek kecil yang hanya dilihat penonton (diulang semasa twist) |
| Bayang di tingkap | Siluet sekejap di tingkap Blok C |
| Zoom perlahan + senyap | Muzik berhenti, kamera masuk perlahan |
| Fokus berubah | Latar kabur jadi jelas, dedahkan sesuatu |

## Rentak TikTok

- Tukar visual setiap 2–4 s (scene baharu, zoom atau tukar sudut).
- Punchline: pegun 0.3 s → zoom masuk pantas → SFX.
- Saat twist: potong ke hitam 0.5 s → dedahkan.
- Bingkai terakhir: rancang supaya bersambung dengan bingkai pertama (gelung) bila sesuai.
