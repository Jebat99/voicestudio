# Panduan TikTok — Menambah Follower

Matlamat: penonton **tonton sampai habis → tonton semula → komen → follow**.

## 1. Video

| Elemen | Peraturan |
|---|---|
| 3 saat pertama | Aksi atau ayat paling aneh. Tiada logo, tiada "Assalamualaikum semua" |
| Rentak | Tukar visual setiap 2–4 s. Re-hook setiap 15–20 s |
| Sari kata | Wajib. Ramai menonton tanpa bunyi |
| Ending | Twist + punchline. Gelung ke bingkai pertama, atau cliffhanger |
| CTA | Disampaikan oleh watak, maks 2–3 s, di akhir |
| Durasi | 60–120 s. Jika kadar tonton penuh rendah, cuba lebih pendek |

## 2. Sebab untuk follow

- **Siri bernombor**: "Kes #1", "Kes #2"… Penonton follow supaya tak terlepas.
- **Watak tetap**: penonton follow watak, bukan video.
- **Misteri musim** (Bilik Muzik Blok C): petunjuk kecil setiap beberapa episod.
- **Episod dua bahagian** sekali-sekala: "Part 2 esok" memberi alasan kukuh untuk follow.
- **Jadual tetap**: cth. 3 episod seminggu pada hari yang sama. Konsisten lebih penting daripada kerap.

## 3. Pos

### Senarai semak sebelum pos

- [ ] Video 1080×1920, sari kata dalam zon selamat
- [ ] Muka depan (*cover*): bingkai paling ekspresif + tajuk pendek (≤ 5 perkataan)
- [ ] Kapsyen: soalan yang mengundang komen + nombor kes
- [ ] 3–5 hashtag (campuran umum dan khusus)
- [ ] Komen pertama disematkan (*pin*): soalan teka-teki atau petunjuk
- [ ] Video ditambah ke **senarai main (playlist)** siri
- [ ] Muzik latar dari pustaka TikTok yang dibenarkan (atau muzik bebas hak cipta)

### Templat kapsyen

```
Kes #[N]: [tajuk pendek] 👀 Siapa korang rasa [soalan]? Komen bawah!
#janimation #animasimelayu #anime #kartunmelayu #misteri
```

### Templat komen disemat

```
Petunjuk ada pada saat [mm:ss] 👀 Perasan tak?
```

## 4. Selepas pos

- Balas komen dalam 1 jam pertama (boleh dalam watak, cth. "— Qis").
- Komen terbaik boleh menjadi idea episod seterusnya (sebut nama pemberi idea dalam kapsyen).
- Gunakan "Balas dengan video" untuk soalan popular.
- Rekod prestasi dalam `prestasi-tiktok.md` selepas 24 jam dan 7 hari.

## 5. Eksperimen (ubah satu perkara sahaja setiap kali)

| Pemboleh ubah | Pilihan untuk diuji |
|---|---|
| Jenis hook | Mula di klimaks / soalan terus / visual mustahil / kenyataan mengejut |
| Durasi | 60 s / 90 s / 120 s |
| Ending | Gelung / cliffhanger / twist tertutup |
| Masa pos | Uji beberapa slot, kekalkan yang terbaik |
| CTA | "Follow untuk part 2" / soalan komen / tiada CTA |

Bandingkan **purata masa tonton**, **% tonton penuh** dan **follower daripada video**, bukan tontonan sahaja.
